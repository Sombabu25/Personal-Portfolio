===============================================================================
                    PERSONAL PORTFOLIO - SETUP GUIDE
===============================================================================

This guide will help you set up and run the Personal Portfolio project locally.

===============================================================================
                            PREREQUISITES
===============================================================================

Before you begin, ensure you have the following installed on your system:

1. Node.js (version 14 or higher)
   - Download from: https://nodejs.org/
   - Verify installation: node --version
   - Verify npm: npm --version

2. Git (optional, for cloning)
   - Download from: https://git-scm.com/
   - Verify installation: git --version

3. A code editor (recommended: VS Code)
   - Download from: https://code.visualstudio.com/

===============================================================================
                         INSTALLATION STEPS
===============================================================================

STEP 1: Clone the Repository (or extract the project files)
-----------------------------------------------------------

If you have the repository URL:
  git clone https://github.com/Sombabu25/Personal-Portfolio.git
  cd Personal-Portfolio

If you have the project files:
  - Extract/unzip the project files to your desired location
  - Navigate to the project directory using terminal/command prompt

STEP 2: Install Dependencies
-----------------------------------------------------------

Open your terminal/command prompt in the project directory and run:

  npm install

This will install all the required packages listed in package.json:
- React and React DOM
- Tailwind CSS
- Lucide React (icons)
- Three.js (3D graphics)
- Vanta.js (3D background effects)
- Testing libraries
- Deployment tools

The installation may take a few minutes depending on your internet connection.

===============================================================================
                           RUNNING THE PROJECT
===============================================================================

OPTION 1: Development Mode (Recommended for development)
-----------------------------------------------------------

To start the development server:

  npm start

This will:
- Start the React development server
- Open the application in your default browser at http://localhost:3000
- Enable hot reloading (changes reflect automatically in browser)

The development server will run until you stop it with Ctrl+C.

OPTION 2: Production Build
-----------------------------------------------------------

To create an optimized production build:

  npm run build

This will:
- Create an optimized production build in the 'build' folder
- Minify and bundle all assets
- Prepare the application for deployment

To test the production build locally:
  - Install a simple server: npm install -g serve
  - Run: serve -s build
  - Access at: http://localhost:5000

===============================================================================
                        TESTING THE APPLICATION
===============================================================================

To run the test suite:

  npm test

This will:
- Launch the test runner in interactive watch mode
- Run all test files in the project
- Show test results in the terminal

Press 'q' to exit the test mode.

===============================================================================
                         DEPLOYMENT INSTRUCTIONS
===============================================================================

OPTION 1: GitHub Pages (Already configured)
-----------------------------------------------------------

The project is already configured for GitHub Pages deployment.

To deploy to GitHub Pages:

  npm run deploy

This will:
- Build the production version
- Deploy to the gh-pages branch
- Make it available at: https://sombabu25.github.io/Personal-Portfolio/

Note: Ensure your GitHub repository has GitHub Pages enabled in settings.

OPTION 2: Other Hosting Platforms
-----------------------------------------------------------

For other hosting platforms (Netlify, Vercel, etc.):

1. Build the project: npm run build
2. Upload the contents of the 'build' folder to your hosting platform
3. Configure your hosting to serve static files

===============================================================================
                        TROUBLESHOOTING
===============================================================================

Issue: "npm install" fails
Solution: 
  - Clear npm cache: npm cache clean --force
  - Delete node_modules folder and package-lock.json
  - Run npm install again

Issue: "npm start" shows port already in use
Solution:
  - Kill the process using port 3000
  - Or use a different port: PORT=3001 npm start (Mac/Linux)
  - Or: set PORT=3001 && npm start (Windows)

Issue: Build fails with errors
Solution:
  - Check for missing dependencies
  - Ensure Node.js version is 14 or higher
  - Delete node_modules and reinstall

Issue: Styles not loading correctly
Solution:
  - Ensure Tailwind CSS is properly configured
  - Check that index.css imports Tailwind directives
  - Restart the development server

===============================================================================
                        CUSTOMIZATION
===============================================================================

To customize the portfolio:

1. Update personal information in components:
   - Header.js: Name, title, social links
   - Contact.js: Email, phone, location
   - Education.js: Academic details
   - Projects.js: Project information
   - Skills.js: Technical skills

2. Update resume:
   - Replace Sombabu_Patel_Resume.pdf in public folder

3. Update profile picture:
   - Replace profile.jpg in src/assets folder

4. Modify styling:
   - Edit Tailwind classes in components
   - Update tailwind.config.js for theme customization
